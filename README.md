# Voice-Based Desktop Assistant - Testing Documentation

## Project Overview
This project focuses on testing a Python-based voice-controlled desktop assistant. The assistant uses speech recognition to execute system commands such as opening applications, searching the web, and responding to predefined queries.

## Objective
To validate the functionality, reliability, and limitations of a voice-based desktop assistant system through structured testing.

## Features Tested
- Speech recognition using microphone input
- Opening applications (Chrome, VS Code, Acrobat, etc.)
- Web navigation (YouTube, Google, Wikipedia)
- System commands (open/close applications)
- Time announcement
- Predefined conversational responses
- Google search functionality
- Alarm feature

## Technologies Used
- Python
- SpeechRecognition API
- pyttsx3 / SAPI (Text-to-Speech)
- pyautogui
- pywhatkit
- OS & Webbrowser modules
